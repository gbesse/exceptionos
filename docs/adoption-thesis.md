# Adoption thesis

This document separates the intended commercial advantage from the capabilities already implemented.

First audience: Order operations teams repeatedly resolving obsolete supplier references.

Potential accumulating asset: Customer-scoped approved precedents, retained with provenance and catalog revisions.

The README is the source of truth for the current alpha. Early publication alone does not make a market position defensible. Existing users, repeat usage and valuable integrations would be needed to establish the thesis. Open formats should make adoption easier; artificial data lock-in is not the objective.

## Next validation milestones

1. Connect one ERP in proposal-only mode and measure time per reviewed exception.
2. Add authenticated multi-user review and a durable single-source case store.
3. Recruit a design partner and measure recurrence, approval rates and unresolved conflicts.
